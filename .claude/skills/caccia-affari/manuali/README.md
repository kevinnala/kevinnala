# Manuali personali

La biblioteca di dominio pubblico già inclusa è in `testi/` (indice in `INDICE.md`).

Metti qui i manuali che possiedi (PDF, scansioni, appunti, tabelle di punzoni,
fotografie di firme certe, cataloghi d'asta scaricati) per dare a Claude più competenza
durante le valutazioni.

Consigli:

- Un file per argomento, con un nome chiaro: `punzoni-argento-italia.pdf`,
  `firme-macchiaioli.pdf`, `marchi-murano.md`, `pokemon-varianti-base-set.md`.
- I PDF di testo (non solo immagini) si cercano meglio. Le scansioni senza testo
  vanno lette pagina per pagina.
- I tuoi appunti di esperienza ("ho comprato X a 30 e venduto a 200 su Y") sono
  preziosissimi: mettili in `appunti-vendite.md` con data, oggetto, prezzo di
  acquisto, canale, prezzo di vendita.

Attenzione: carica solo materiale che hai il diritto di usare, e non pubblicare il
repository se contiene libri protetti da diritto d'autore (tienilo privato).
